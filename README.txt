RAXXY CINE WEBSITE

CARA MENJALANKAN:
1. Ekstrak file ZIP.
2. Buka folder "raxxy_cine_website" di Visual Studio Code.
3. Buka file index.html.
4. Klik kanan lalu pilih "Open with Live Server" (jika ekstensi Live Server sudah dipasang).
   Atau klik dua kali index.html untuk membukanya langsung di browser.

FILE:
- index.html : struktur halaman dan isi website
- style.css  : desain, warna, layout, dan responsive mobile
- script.js  : menu mobile dan demo formulir kontak

YANG PERLU KAMU UBAH:
- Email raxxycine@email.com dan Instagram @raxxy.cine di index.html.
- Produk contoh dan deskripsinya di bagian OUR COLLECTION.
- Testimoni contoh dengan ulasan pelanggan asli.
- Form kontak saat ini hanya demo tampilan; belum mengirim pesan ke email/server.

Website ini menggunakan HTML, CSS, dan JavaScript biasa, jadi bisa diedit di Visual Studio Code.

BRAND IMAGE:
- raxxy-cine-brand.png adalah gambar brand yang kamu kirim dan dipakai pada bagian hero website.
- Jika ingin mengganti gambar, gunakan nama file yang sama atau ubah alamat src pada index.html.
